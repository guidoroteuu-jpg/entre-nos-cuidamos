# Architecture rules
- Browser-persisted React state must restore after hydration and defer writes until restoration completes; use `usePersistedState` for editable JSON state so SSR stays browser-independent and saved data is not overwritten.
- Vitest uses its own config with deduplicated, inlined React dependencies so hook tests share the renderer's React instance without running application build plugins.
- School administration uses authenticated server functions and school_members for school-scoped assignments; privileged account creation verifies the caller's administrator membership before loading the admin client, and signup metadata never grants roles.
- New authenticated screens live under the shared _authenticated gate; auth changes invalidate routing once at the root and logout clears cached private data before ending the session.
